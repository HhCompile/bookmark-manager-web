## 🎨 设计偏好

### 1. 弹窗/对话框设计

#### 1.1 操作按钮位置
**偏好**: 按钮固定在弹窗底部，不随内容滚动

```
┌─────────────────────────────┐
│  标题                        │
├─────────────────────────────┤
│                             │
│  内容区域（可滚动）           │
│                             │
│  ┌─────────────────────┐   │
│  │                     │   │
│  │   书签列表...        │   │
│  │                     │   │
│  └─────────────────────┘   │
│                             │
├─────────────────────────────┤ ← 分割线
│  [     查看书签      ]      │ ← 固定底部
└─────────────────────────────┘
```

**理由**:
- 主要操作按钮始终可见
- 用户无需滚动即可执行关键操作
- 减少操作路径，提升效率

**实现要点**:
- 内容区域: `flex-1 overflow-y-auto`
- 按钮区域: `flex-shrink-0 border-t bg-background p-4`
- 使用分割线 (`border-t`) 区分内容与操作区

### 2. 响应式设计偏好

#### 2.1 移动端适配
- 弹窗宽度: `w-[calc(100%-2rem)]` 保持两侧边距
- 内边距: `p-4 sm:p-6` 移动端更小
- 字体大小: 使用响应式类 `text-sm sm:text-base`

#### 2.2 触摸友好
- 按钮高度: 最小 44px (iOS 标准)
- 列表项间距: 适当增大，方便点击

### 3. 视觉风格偏好

#### 3.1 色彩使用
- **成功状态**: 绿色系 (`bg-green-100`, `text-green-600`)
- **主按钮**: 绿色 (`bg-green-600`)
- **标签序号**: 蓝色 (`bg-blue-100`, `text-blue-600`)
- **背景**: 浅灰 (`bg-gray-50`)

#### 3.2 圆角风格
- 卡片: `rounded-lg` (8px)
- 按钮: `rounded-md` (6px)
- 图标容器: `rounded-full`

#### 3.3 阴影/层次
- 弹窗: `shadow-lg`
- 悬停效果: `hover:shadow-lg transition-all`

## 🎈 交互偏好

### Tooltip 气泡提示

**使用场景**:
- 操作按钮悬浮提示（打开、编辑、删除）
- 状态图标说明（锁定、失效）
- 标签数量溢出提示

**实现方式**:
```tsx
<Tooltip>
  <TooltipTrigger asChild>
    <button>
      <Edit className="w-4 h-4" />
    </button>
  </TooltipTrigger>
  <TooltipContent>
    <p>编辑书签</p>
  </TooltipContent>
</Tooltip>
```

**显示时机**: `delayDuration = 0`（立即显示）

## 🎯 设计原则总结

1. **操作优先**: 关键操作按钮始终可见，不被内容遮挡
2. **清晰层次**: 使用分割线、背景色区分不同区域
3. **响应适配**: 移动端和桌面端有不同的尺寸标准
4. **一致色彩**: 状态色（成功/错误）保持一致
5. **流畅动画**: 适度的动画提升体验，不过度设计
